# C-beancount-parser

A recreational C project that implements a simple Beancount parser from scratch.

## Users' Discretion

Note that the functions of the parser may be limited, the implementation may not be optimal, and errors may occur.

## Changes

GNU GPLv2 requires me to state changes made to the licensed material, in this case, `beancount`. I didn't make any.

As I did all the programming without referring to the `beancount` repository, similarities in implementation, if any, are purely coincidental and unexpected.
